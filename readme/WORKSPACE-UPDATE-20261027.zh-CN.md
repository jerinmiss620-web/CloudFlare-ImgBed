# 工作台常用功能更新（2026-10-27）

本次基于已经改造过的小苍兰界面，保留上方上传、下方图库。只需更新你自己的 `jerinmiss620-web/CloudFlare-ImgBed` 中的 `frontend-dist/`，不需要修改公共前端仓库。

## 新增入口

1. **新建文件夹**：位于“上传新文件”右侧。填写当前目录下的文件夹名称，可以预览完整路径，点击“创建并进入”后直接在该目录上传。
2. **同名目录提示**：如果当前已加载的列表里有同名文件夹，按钮变为“打开文件夹”。搜索结果或尚未加载的目录不能保证完整查重；即使目标已存在，也沿用原路径上传，不会额外创建副本。
3. **返回上一级**：位于图库标题右侧，根目录下自动禁用，手机端也可直接点击。
4. **刷新图库**：位于图库标题右侧，刷新期间显示加载状态，刷新后尽量保留仍在列表中的勾选文件。
5. **清除搜索与筛选**：搜索或筛选生效时出现快捷按钮，一次清除关键词、包含/排除标签及全部筛选条件，保留当前目录和排序偏好。

## “新建文件夹”的保存规则

按你确认的方式，沿用原上传页的规则：**先准备上传目录，首次成功上传文件后，目录才保存到图库。**

- 未上传文件的空文件夹不会单独写入服务器，也不会伪造一个本地持久化目录。
- 弹窗和进入新目录后的提示均说明这一点。
- 从新建入口进入目录时，会清除搜索和筛选，避免新上传的文件因筛选而被隐藏。
- 输入框支持回车确认，打开弹窗时自动聚焦；名称校验复用现有路径规则，新名称不能包含斜杠、路径穿越等非法内容。
- 支持在当前相册下建立子目录；已有父路径中的历史特殊字符保持原样。
- 已经进入准备/上传队列的文件，仍保存在它们提交时固定的目标目录。新建或切换目录不会改写这些文件的目的地。

这次没有新增后端接口，也没有修改上传请求、渠道、压缩、命名、存储、会话或权限规则。
